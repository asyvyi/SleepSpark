# Sleepspaark

Sleepspaark is a sleep calculator website designed to help users plan their sleep schedules. It provides estimated bedtimes and wake-up times based on sleep duration and sleep cycles, offering a simple way to organize and understand sleep routines.

## Features
- Sleep time calculations
- Suggested bedtimes and wake-up times
- Sleep-cycle-based estimates
- Simple and intuitive interface

## Technologies
- HTML
- CSS
- JavaScript
